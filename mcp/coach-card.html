A measured starting point for game settings, not a guarantee of zero drift. No settings are applied.

Why this value—and can I go lower?

A deadzone ignores a small area around the stick’s center. For example, 2% describes the center area ignored by that game setting, not a measured amount of controller drift.

The suggestion adds a margin to the recorded resting movement. It is a conservative place to start, not a required minimum. Keep a lower setting if it already feels stable. Otherwise lower gradually while checking that your aim or movement stays still after releasing the stick.

0% is an option to test, not a calibration target. Use the lowest setting that stays stable in play. Games use different scales; a preset such as Small is not an exact percentage.

Do I need to save a report or create a profile?

Completed check reports are recorded on this computer automatically. Download result image saves a picture for sharing; neither action saves calibration.

You do not need a game profile here. Set game options in the game itself. A temporary controller adjustment is a separate choice, followed by a retest and an explicit Save calibration to controller decision.
